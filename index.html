Diccionario Git

Explora los comandos esenciales de Git mediante una interfaz moderna y profesional.

01

git init

Inicializa un nuevo repositorio local dentro de la carpeta actual para comenzar a controlar versiones.

02

git clone

Descarga una copia exacta de un repositorio remoto para trabajar localmente en el proyecto.

03

git add

Agrega cambios al área de preparación para incluirlos posteriormente en un commit.

03

git commit

Guarda una captura de los cambios preparados en el historial
